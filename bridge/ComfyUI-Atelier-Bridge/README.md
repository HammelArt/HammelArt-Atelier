# ComfyUI-Atelier-Bridge

Zero-node companion extension for **HammelArt Atelier** (`v0.9.6-beta+`).

## Automatic Setup (Recommended)
Open **HammelArt Atelier → `?` → `05 ComfyUI`** while ComfyUI is running and click **Install Atelier Bridge**. Atelier automatically detects your active ComfyUI `custom_nodes` directory via local `127.0.0.1` endpoints and installs this folder cleanly — no extra nodes required on your canvas.

## Manual Installation
Copy this `ComfyUI-Atelier-Bridge` folder into your `ComfyUI/custom_nodes/` directory and restart ComfyUI once.
